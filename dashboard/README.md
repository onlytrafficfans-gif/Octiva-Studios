# Octiva Dashboard

The unified dashboard is intentionally deferred until the initial engines have passed real generation tests.

Planned navigation:

- Create
- Projects
- Studio
- Library
- Lyrics
- Stems
- Vocals
- Mix
- Master
- Engines
- Settings

The Create screen should be simple and fast. Advanced production tools should appear after a song is created or imported.

The dashboard must communicate through Octiva adapters rather than directly importing engine internals or iframing upstream UIs.
